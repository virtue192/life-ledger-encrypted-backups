# Life Ledger OS Encrypted Backups

This private repository stores encrypted JSON backups exported from Life Ledger OS.

- Repository: https://github.com/virtue192/life-ledger-encrypted-backups
- Content policy: encrypted records only
- Do not commit passwords, .env files, Supabase keys, or plaintext exports
- Restore path: import the JSON file in Life Ledger OS settings, then unlock with the original password
